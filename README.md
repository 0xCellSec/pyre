# PYRE (PYRE's Your Recon Engine)
Automated nmap + wfuzz orchestration for recon workflow

**This tool is intended only for CTF purposes and shouldn't be used against real infrastructure**

## What is the goal?
PYRE's name suggest it would be more autonomous instead of just automating some aspects. My hopes for this project is to include at least the most common services for HTB boxes into the automation workflow like http, smb, ftp, etc. I also believe I should add an automated CVE search  

## current state? 
At the moment, PYRE only automates nmap + wfuzz directory and subdirectory enumerations on an HTB target

## Inspiration
This project is heavily inspired by AutoRecon, a more sophisticated network reconnaissance/service enumeration tool.
